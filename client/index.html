The Past...in Order

card testing

    How To Play:

    • You'll be given a number of events with a small description of each one.
    • Your role is to move the cards into chronological order using the up or down button on each card.
    • Once you think you've got them in the correct order, click the 'check answers' button to see.
    • If you're right, you'll move onto the next level.
    • Each level will increase the number of dates you need to order.
